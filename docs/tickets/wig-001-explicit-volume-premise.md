# WIG-001 — 约束推导显式化「可用发量前提」并补齐 rules/ 测试覆盖

**Spec**: `docs/specs/wig-assisted-hairstyle-options.md`
**Blocked by**: 无 — 可立即开始
**Triage**: ready-for-agent

## 交付

约束推导函数接受一个显式的 **Available Volume Premise** 入参。传「自身信号」时行为与今天
**逐位一致**；传「充足」时发量支撑与发际线暴露两维不产生排除。

同时为 `src/features/appearance-agent/rules/` 建立首次测试覆盖 —— 该目录目前零测试，
却承载全部带「实测」依据的确定性规则。

## 为什么先做这一票

纯前置重构（prefactor），不改变任何现有行为。它把「前提」从隐含变为显式，后续两轮
推荐才能用同一份规则、同一个函数跑两个前提，而不是长出第二套逻辑。

## 验收

- 前提为自身信号时，既有全部分支的输出不变 —— 特别是「仅视觉判定发量薄、无自报 →
  无约束」这一条（它是防止短发用户被误推假发的关键防线，实测依据见文件头注释）。
- 前提为「充足」时：不排除任何发量档位，不强制遮额。
- 脸型适配不受本票影响（它不属于这个函数）。
- `npm test` 全绿。
