# WIG-003 — 假发方案推导纯函数（唯一新增接缝）

**Spec**: `docs/specs/wig-assisted-hairstyle-options.md`
**Blocked by**: WIG-001（前提入参的类型签名）、WIG-002（属性表维度）
**Triage**: ready-for-agent

## 交付

一个纯函数，输入两轮候选与门槛所需信号，输出假发方案。它承担四件事，全部在这一个
点上可测 —— 无数据库、无任务队列、无模型替身。

1. **差集** = 第一轮候选 \ 第二轮候选
2. **开放条件**（三条须同时成立）：短期场景 track、用户侧依据（自报困扰或显式确认）、
   形态匹配后可行款 ≥ 1
3. **形态匹配**：确定性查表 → 只补量感 / 整顶
4. **fail closed**：维度未标注或判据不足 → 不进入方案，并产出 Human Escalation 记录

## 验收

- 差集为空 → 不产生方案。
- 日常通勤场景（非短期 track）→ 不开放，即使差集非空。
- 缺用户侧依据 → 不开放，即使场景与差集都满足。
- 只被发量挡住、本身遮额的款式 → 只补量感形态。
- 被遮额挡住的非极短款式 → 整顶形态。
- 极短露头皮款式 → 排除，不出现在方案中。
- 维度未标注 → 不进入方案，并产出升级记录。
- 可行款为 0 → 不开放入口。
- `npm test` 全绿。
